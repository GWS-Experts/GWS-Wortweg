# GWS-Wortweg

Kostenlose App, mit der Englischsprachige Deutsch lernen. Die Lektionen folgen einer Geschichte: Emma Clarke aus Leeds zieht nach Marzling und lernt Schritt für Schritt, den deutschen Alltag zu meistern.

- Lerninhalte: siehe [`content/`](content/README.md)
- Inhalte prüfen: `node scripts/validate-content.mjs`
